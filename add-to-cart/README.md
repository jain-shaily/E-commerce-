# 🛒 E-Commerce Website

A responsive E-Commerce website built using React and Vite. The project includes authentication, product listing, shopping cart functionality, and a clean user interface.

## 🚀 Live Demo
https://e-commerce-29ew41bx0-shaily-jain.vercel.app

## 📂 GitHub Repository
https://github.com/jain-shaily/E-commerce-

## ✨ Features
- User Login & Logout (Firebase Authentication)
- Product Listing
- Shopping Cart
- Quantity Selector
- Category-wise Products
- Responsive Design
- Toast Notifications
- Protected Routes

## 🛠️ Tech Stack
- React.js
- Vite
- React Router DOM
- Firebase Authentication
- React Toastify
- CSS

## 📁 Project Structure

```
src/
├── components/

├── routes/
├── assets/
└── main.jsx
```

## ⚙️ Installation

```bash
git clone https://github.com/jain-shaily/E-commerce-.git
cd add-to-cart
npm install
npm run dev
```
